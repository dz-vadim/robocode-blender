Blender: модифікатори і референси

Unity 3D · урок 6 «Модифікатори у Blender. Додавання референсів» · Blender 5.2

Як дивитися відео. Відео грає без зупинок; Пробіл — пауза, ← / → — крок назад / вперед, швидкість 0.5–1.5×. Хочеш, щоб воно чекало на тебе після кожного кроку, — постав галочку «зупинятися після кроку». R — показати крок ще раз. Жовтим унизу — клавіші.

1Модифікатори

Модифікатор — автоматична дія, яка змінює вигляд об'єкта, не чіпаючи його геометрію. Його можна вимкнути, прибрати або поміняти місцями з іншими — модель від цього не зламається.

Де / щоЩо робить

Іконка моніторатимчасово вимкнути модифікатор

˅ → Apply (лише в Object Mode, Tab)застосувати: зміни стають справжньою геометрією, яку можна редагувати

2Симетрія: Mirror

Робимо лише половину моделі — друга половина повторює все сама.

Axis — вісь, уздовж якої відрізали половину (у нас Y). Clipping — вершини на середині «прилипають» до площини дзеркала: половинки не розходяться і не залазять одна в одну.
Дзеркальну половину не виділити — так і має бути. Редагуй лише справжню.

3Референси і кіт-робот

Референс — картинка, по якій моделюємо. Ставимо дві: спереду і збоку, робимо напівпрозорими й підганяємо кожне кільце моделі під контур.

Референс: Numpad 3 / Numpad 1 — вид збоку / спереду → Shift+A → Image → Reference → вибери картинку. У властивостях картинки (Object Data): Opacity 0.3, Depth: Front, Show In: Only Axis Aligned — картинку видно лише у видах 1 / 3, і вона не заважає крутити модель.

Увесь кіт — одне відео (52 кроки). Список кроків під відео — щоб перейти одразу до потрібного.

ПрийомЯк
Кільце під референсAlt+ЛКМ по кільцю → S (або S X / S Y) → G — до контуру на картинці
Кругле пласке кільцеграні → I → ПКМ → LoopTools → Circle, потім Flatten (додаток LoopTools: Edit → Preferences → Get Extensions)

Пальці окремоAlt+E → Extrude Individual Faces
РозрізиCtrl+R — петля; K — ніж (ЛКМ по точках, Enter)
Не обов'язково точно як у відео. Числа в підписах — підказка; головне, щоб кільця лягали на контур референсу. Тягни мишею і дивись на картинку.
Збережи: Ctrl+S → robocat.blend.
