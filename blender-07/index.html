Blender: матеріали, UV-розгортка, текстура

Unity 3D · урок 7 «Текстури. UV-mapping. Матеріали» · Blender 5.2

Як дивитися відео. Відео грає без зупинок; Пробіл — пауза, ← / → — крок назад / вперед, швидкість 0.5–1.5×. Хочеш, щоб воно чекало на тебе після кожного кроку, — постав галочку «зупинятися після кроку». R — показати крок ще раз. Жовтим унизу — клавіші.

Працюємо з котом-роботом з уроку 6: спершу даємо йому матеріали, потім розрізаємо швами й розгортаємо, а наприкінці малюємо текстуру прямо в Blender. Покроково з картинками — інструкція уроку.

1Матеріали

Матеріал — з чого «зроблений» об'єкт: колір, блиск, метал чи пластик, чи світиться. Щоб бачити матеріал наживо — Object Mode і Viewport Shading → Material Preview (кулька вгорі праворуч або Z).

ПараметрЩо робить
Base Colorосновний колір
Metallicметалевий блиск (0 — пластик, 1 — метал) — для роботів
Roughnessгрубість: 0 — гладкий, як дзеркало, 1 — матовий
Specularсила відблиску (схоже на Metallic, але не те саме)
Subsurfaceсвітло проходить крізь напівпрозоре (шкіра, віск)
Emissionоб'єкт ніби світиться (Color + Strength)
Кілька матеріалів на одній моделі: + (новий слот) → New → Tab → виділи грані → Assign. Експериментуй: один кіт — різні кольори.

2Шви й UV-розгортка

UV-розгортка — модель, «розрізана» і розкладена на площині, як викрійка. На неї потім лягає картинка-текстура. Вкладка UV Editing: праворуч модель, ліворуч розгортка.

ДіяЯк
Шоввиділи ребра (Alt+ЛКМ — усе кільце) → ПКМ → Mark Seam
Прибрати шовПКМ → Clear Seam
РозгорнутиA → U → Unwrap
Щільніше розкласти шматкиу розгортці: UV → Pack Islands
Зберегти розгортку картинкоюUV → Export UV Layout (для GIMP / Photoshop)
Де різати? Уяви, що модель — паперова фігурка: де треба розрізати, щоб розкласти її на столі? Руки й ноги — трубки: кільце там, де кріпляться, і одна лінія вздовж (з того боку, якого менше видно). Наш кіт — половина з Mirror, тож по середині вже розрізаний.
Шматки не мають налазити один на одного — інакше фарба з одного місця з'явиться в іншому. Налізли — додай шов і зроби Unwrap ще раз. Кисті й пальці — найскладніші, тут нормально пробувати кілька разів.

3Текстура в Blender

Малюємо прямо по моделі у вкладці Texture Paint. Перша текстура — проста: лише кольори.

ЩоЯк
Нова текстураTexture Slots → + → Base Color → ім'я, 1024 × 1024, колір → OK
Колір і розмір пензлякольоровий прямокутник угорі; розмір — F і рух мишею
Фарбувати лише потрібнекнопка-кубик Paint Mask; грані виділяй у Tab і повертайся в Texture Paint
Залити все одним кольоромінструмент Fill зліва
Зберегти малюноку розгортці: Image → Save As → robocat.png
Збережи картинку! Ctrl+S зберігає модель, але не намальовану текстуру. Без Image → Save As малюнок зникне після закриття Blender.
