Урок 7: матеріали, розгортка, текстура — покроково

Урок 7 · кіт-робот з уроку 6. 31 крок (відео — у плеєрі уроку). Біля кожного кроку — картинка «що має вийти» і посилання на коротке відео.

Головні правила
  • Матеріал видно лише в Material Preview і в Object Mode (або в Texture Paint).
  • Шви — як розрізи паперової фігурки. Руки й ноги — трубки: кільце там, де кріпляться, і одна лінія вздовж.
  • Шматки розгортки не мають налазити один на одного — інакше фарба з'явиться не там. Налізли — додай шов і Unwrap ще раз.
  • Збережи картинку окремо: Image → Save As.
Шпаргалка: Z вид (Material Preview) · Tab редагування · 2 / 3 ребра / грані · Alt+ЛКМ кільце · ПКМ → Mark Seam шов · U → Unwrap розгорнути · F розмір пензля · Image → Save As зберегти картинку.

1Матеріали

1Відкрий кота

Відкрий свого кота з уроку 6: File → Open (Ctrl+O). Працюємо в Object Mode — так видно матеріали.

Ctrl+O

▶ відео кроку

2Material Preview

Угорі праворуч у в'юпорті — кулька Material Preview (або Z → Material Preview). Тепер видно, як виглядатиме матеріал.

Z Material Preview

▶ відео кроку

3Новий матеріал

У правій панелі — вкладка Material (червона кулька) → + New.

Material New

▶ відео кроку

4Колір

Base Color — клікни по кольору і вибери помаранчевий.

Base Color

▶ відео кроку

5Метал

Metallic = 0.8 — кіт блищить, як справжній робот.

Metallic 0.8

▶ відео кроку

6Гладкість

Roughness = 0.35 — чим менше, тим гладкіша поверхня і чіткіші відблиски.

Roughness 0.35

▶ відео кроку

7Світіння

Emission: колір і Strength 2 — кіт ніби світиться. Спробуй і поверни 0.

Emission Strength

▶ відео кроку

8Другий матеріал

+ праворуч від списку матеріалів (новий слот) → New → назви «Екран»: колір темний, Emission блакитний, Strength 0.6.

+ New

▶ відео кроку

9Екран на обличчі

Tab → 3 (грані) → клікни грань екрана на обличчі → Assign. Екран отримав свій матеріал.

Tab 3 ЛКМ Assign

▶ відео кроку

10Готово

Tab — вийди з редагування і покрути кота. Пограй з кольорами!

Tab

▶ відео кроку

2Шви й UV-розгортка

11Вкладка UV Editing

Вгорі — вкладка UV Editing: праворуч модель, ліворуч її розгортка.

UV Editing

▶ відео кроку

12Без швів — погано

A → U → Unwrap. Без швів усе зім'ялося в один шматок — так текстуру не намалюєш.

A U Unwrap

▶ відео кроку

13Шов: плече

2 (ребра) → Alt+ЛКМ по кільцю, де рука виходить з тулуба → ПКМ → Mark Seam. Шов стає червоним.

Alt+ЛКМ ПКМ Mark Seam

▶ відео кроку

14Шов: рука знизу

Знизу руки — ЛКМ по ребру вздовж руки → ПКМ → Mark Seam. Так «трубка» руки розгорнеться в прямокутник.

ЛКМ ПКМ Mark Seam

▶ відео кроку

15Шов: зап'ястя

Alt+ЛКМ по кільцю на зап'ясті → Mark Seam. Кисть буде окремим шматком.

Alt+ЛКМ ПКМ Mark Seam

▶ відео кроку

16Шов: стегно

Знизу: Alt+ЛКМ по кільцю вгорі ноги → Mark Seam.

Alt+ЛКМ ПКМ Mark Seam

▶ відео кроку

17Шов: нога ззаду

Ззаду ноги: ЛКМ по ребру, Shift+ЛКМ по наступних донизу → Mark Seam.

ЛКМ Shift+ЛКМ ПКМ Mark Seam

▶ відео кроку

18Шов: щиколотка

Alt+ЛКМ по кільцю над ступнею → Mark Seam. Ступня — окремий шматок.

Alt+ЛКМ ПКМ Mark Seam

▶ відео кроку

19Шов: шия

Alt+ЛКМ по кільцю між шиєю і головою → Mark Seam.

Alt+ЛКМ ПКМ Mark Seam

▶ відео кроку

20Розгорнути

A → U → Unwrap. Тепер кіт розрізаний по швах: рівні шматки, як викрійка. Тулуб і голова вже розрізані посередині — у нас половина з Mirror.

A U Unwrap

▶ відео кроку

21Збережи

Ctrl+S. Червоні лінії — шви, ліворуч — розгортка.

Ctrl+S

▶ відео кроку

3Текстура в Blender

Вгорі — вкладка Texture Paint: малюємо прямо по моделі.

Texture Paint

У правій панелі Texture Slots → + → Base Color: ім'я RoboCat, 1024 × 1024, колір помаранчевий → OK. Ліворуч з'явилась помаранчева картинка з розгорткою.

+ Base Color OK

▶ відео кроку

24Колір пензля

Угорі клікни кольоровий прямокутник і вибери темний колір.

Color

▶ відео кроку

25Маска граней

Кнопка-кубик Paint Mask угорі: фарба лягає лише на виділені грані. Грані виділяй у Tab (Edit Mode), потім знову Tab → Texture Paint. Невиділені грані стають світлішими — так і має бути.

Paint Mask Tab

▶ відео кроку

26Кисті

Tab → виділи грані кисті → Tab → затисни ЛКМ і фарбуй кисть.

Tab ЛКМ Tab ЛКМ

▶ відео кроку

27Ступні

Так само: виділи грані ступні → фарбуй.

Tab ЛКМ Tab ЛКМ

▶ відео кроку

28Таз

Виділи грані таза → фарбуй — вийдуть «шорти».

Tab ЛКМ Tab ЛКМ

▶ відео кроку

29Вуха

Виділи передні грані вух → фарбуй.

Tab ЛКМ Tab ЛКМ

▶ відео кроку

30Збережи картинку!

Ліворуч: Image → Save As → robocat.png. Ctrl+S цього не робить — без Save As малюнок зникне.

Image Save As

▶ відео кроку

31Готово

Tab → Object Mode, покрути кота. Хочеш ще — додай свої смужки й візерунки.

Tab

▶ відео кроку

Щось пішло не так? Ctrl+Z — крок назад. Подивись відео кроку ще раз: зверни увагу, які саме грані виділено і звідки дивиться камера.
